# 配色与视觉语言

Candlewick 的三个窗口、菜单栏 / 任务栏上的文字和菜单里的涨跌色用的是同一套配色。值只有一处：`src/ui/theme.rs` 的 `Palette::new`，按系统外观取浅色或深色，`theme::apply` 把它装进 GPUI Kit 的主题；窗口换外观或改了「红涨绿跌」时重装一次。视图从 `Palette` 取色，不写颜色字面量。

## 来源

应用图标：深海军蓝底上一条从紫 → 青 → 薄荷的价格线，末端一个发亮的点。配色就从这条线上取：

| 字段 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `glow` | `#0076af` | `#49c8f3` | 唯一的强调色：控件、折线、当前项、侧栏里的钱包条 |
| `mint` | `#009365` | `#56ecb5` | 「实时」的点、持仓分布条末端亮着的点、一条均线 |
| `violet` | `#7456e0` | `#aaa0fb` | 第二序列色，画线默认用它 |
| `amber` | `#c5770f` | `#f7b83d` | 连接中、读取中、接近强平，一条均线 |
| `green` / `red` | `#008047` / `#d42e3d` | `#30d792` / `#ff6e74` | 涨跌，经 `up` / `down` 按「红涨绿跌」互换 |

文字和线是带海军蓝色相的灰，以 alpha 叠在窗口材质上，所以同一组值在任何桌面背景、vibrancy 或 Mica 上都成立：

| 字段 | 值 |
|---|---|
| `foreground` / `muted` / `faint` | 92% / 56% / 36% 的墨色 |
| `border` / `input` | 10% / 12%（深色 13%） |
| `panel` | 白色 50%（深色 3.5%），配 18px 圆角和一条边线：窗口里抬起的面板 |
| `fill` / `fill_strong` | 4.5% / 7.5%（深色 5.5% / 9%）：统计块、分段控件、悬停行的填充 |
| `popover` | `#fafcff` 92%（深色 `#23262e` 94%）：悬停卡片和弹出的菜单 |
| `series` | 七个序列色，依次是 glow、violet、mint、amber、淡紫、墨色 30%、墨色 16%（深色 18%）：持仓分布的份额，末尾两格是「其余」和稳定币 |

## 原生侧

菜单栏和任务栏由平台代码绘制，行情图由 `src/ui/chart/` 绘制；值都取自同一处：

- macOS：`src/platform/macos/ticker.rs` 用 `src/ui/theme.rs` 的 `GREEN` / `RED` 造动态 `NSColor`（`colorWithName:dynamicProvider:`），给菜单行里的涨跌数字和菜单栏双排图像上色；菜单文字本身由系统绘制。
- Windows：`src/platform/windows/portable/color.rs` 的 `Palette::taskbar`，用于任务栏行情条的涨跌混色、托盘图标的圆点和菜单行首的三角标记。文字色仍是 Windows 11 的 TextFillColor，和任务栏上其他项一致。
- 行情图：K 线、折线和层都用 `Palette`，所以图表跟着这里走。

## 语言

三个窗口共用「原生质感的数据极简」：系统字体（主题的基准字号 Windows 14px、macOS 13px，见 `theme::apply`），数字用等宽数字（`ui::tabular`，OpenType `tnum`）；一个大数（34px semibold，变化时闪一下涨跌色）+ 一行说明；分段控件是胶囊（`widgets::pill_tabs`）；主体内容放在 `panel` 上，列表像盘口一样紧凑、右对齐，数字背后用低透明度的条表示占比；底部一排 `fill` 的统计块（`widgets::stat_tile`）。状态用一个点表达：mint 实时、amber 忙、red 出错、faint 过期（`widgets::status_dot`）。

改配色只改 `src/ui/theme.rs`：`Palette::new` 里的值，和涨跌色的两个常量 `GREEN` / `RED`。菜单栏和任务栏的绘制也从这里取，别在视图里写颜色字面量。

## 行情图上的层

`src/ui/chart/canvas.rs` 画 K 线和坐标轴；它之上的东西由 `src/ui/chart/overlay.rs` 画在同一块画布上（`src/ui/chart/overlay/paint.rs`），每帧按当前的几何（缓动后的时间和价格区间）重画，所以拖动、缩放和实时跳动时都贴着 K 线走。颜色全部来自 `Palette`：

| 东西 | 画法 |
|---|---|
| 十字线 | 1px 墨色 30% 的虚线（段长 3px）；竖线吸附在 K 线中心，横线跟指针，靠近开高低收时吸附，并在交点上画一个 6px 的实心点。价格和时间各一个反色标签（填充是线或墨色、文字用背景色，圆角 5px，18px 高）贴在坐标轴外沿 |
| 悬停卡片 | GPUI 元素（`src/ui/chart/panels/hover.rs`），不是画布：圆角 12px、一条边线、`popover` 底、12px 字、等宽数字。首行是时间和这根 K 线相对开盘的涨跌（涨跌色），下面两行开高低收，再一行振幅，开了指标时底部每行一个色点、名字和这根 K 线上的值。跟着指针走，离指针 14px，到边缘就翻到另一侧；最窄 176px |
| 画线 | 默认 `violet`（和折线的 glow 区分开），选中或被指着时换 `glow`，两端画手柄：9px 的 glow 圆，里面 6px 的背景色。水平线在价格轴上有自己的标签；斐波那契从前一端画到右边缘，七条水平线之间铺由浅到深的色带（alpha 0.035 起，每级加 0.012），标签「0.618  价格」放在线左端上方，两端之间一条 35% 的虚线；测量是涨跌色 9%（悬停 12%）的矩形加 60% 的边，读数卡 44px 高、圆角 8px，第一行涨跌幅和差价用涨跌色，第二行根数和时长用 56% 的墨色（`muted`） |
| 指标 | 1.25px 线：MA 依次 violet、amber、mint，EMA 用文字色；布林带用 glow，外轨 1px 55%，中轨虚线，带内填 7%。图左上角一行图例：6px 色块、名字、当前值（悬停时是那根 K 线上的值），11px |
| 工具栏 | 图表头部行里一枚胶囊（`src/ui/chart/toolbar.rs`）：光标、水平线、趋势线、斐波那契、测量，一条分隔线后是指标菜单（Σ），按下的那个换成卡片底色并带一点阴影。有画线时出现橡皮擦，删过东西后出现撤销 |

画布上的文字用系统字体 11px（斐波那契的层级标签 10px）；悬停卡片是 GPUI 元素，数字用等宽数字。
