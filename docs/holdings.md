# 持仓窗口

`src/ui/holdings/` 展示自动同步账户与本地登记持仓的同一份组合。持仓窗口、系统栏总额、菜单明细和 AI `/v1/portfolio` 都来自 `Model::portfolio()`。组合计算只消费账户、登记报价和汇率，统一合并一次资产。系统栏一次渲染共用一份组合快照，持仓总览与登记编辑器共用同一份 `Arc<Portfolio>`。

## 登记持仓

窗口标题栏的「登记持仓」打开管理界面；没有交易所 API Key 时也能进入。先通过共用的 `ui/instrument_picker.rs` 搜索并选择行情标的，再填写持有平台或账户、数量和可选单位成本。支持新增、编辑、取消和带确认的删除。平台是资产存放的位置，行情来源负责报价，二者独立。

没有手填价格字段。登记后，标的会自动加入行情订阅，无需加入自选。更新价格、行情连接状态和汇率会通知持仓窗口重新估值。编辑或删除时同步调整订阅，只取消已经没有其他使用者的标的。自选变更、登记变更和同花顺同步通过 `Shared::update_instruments` 在同一个模型临界区内更新数据、清理失去使用者的报价并发布订阅，界面与 HTTP 写入共用这条路径。登记的数量、成本和行情元数据存入配置目录的 `manual-holdings.json`，先写临时文件并重命名，再发布到内存。交易所账户刷新不会覆盖登记记录。最多 500 条记录，同一标的的多笔持仓共用订阅；每帧报价的标的查找使用哈希索引。

- A 股股票、ETF、场内 LOF 使用同花顺等已有来源，仍需来源所需的凭据。
- 普通场外基金和黄金基金使用东方财富 `eastmoney:150.<六位基金代码>`，填写基金份额，成本为人民币每份。价格是最新公布单位净值，15 分钟查询一次；界面按上海日期显示净值日期。收益型货币基金和外币份额暂不支持。
- 上金所 Au99.99 使用 `eastmoney:118.AU9999`，数量为克、成本为人民币每克，每 15 秒查询一次。
- 支付宝的黄金基金要选实际基金代码。基金份额和克数属于不同单位，不能混用。
- 美股、港股、加密交易对和链上池子也能使用各自的已有行情来源。

仅登记自动同步账户以外的持仓。同一笔资产同时自动同步和登记会重复计入。

## 估值与来源

组合的 `accounts` 保留各交易所权益、钱包和刷新状态；`manualHoldings` 保留登记记录及每条报价、来源时间、收到时间、估值、盈亏和错误；`assets` 按稳定身份合并，`held` 同时列出交易所钱包和登记平台。股票/ETF 使用带市场后缀的代码作为身份，场外基金使用独立行情 ID，避免把场内成交价和场外净值合并。资产名称只用于显示。

自动同步账户按原来的美元口径估值。登记持仓按原币单价乘数量，再通过 USD/CNY、USD/HKD、USD/JPY 日参考汇率折成 USD。外币汇率缺失时，对应持仓暂不计入总额，不按 USD 冒算。非美元计价的加密币对订阅计价币的 USDT 报价用于换算。CNY / USD / JPY 显示设置最后统一换算总额、资产、钱包和盈亏；登记的原币价格和成本保留原币单位。

没有报价或汇率的记录保留数量并显示等待原因；`partial` 为 true，窗口说明总额只包含可估值部分。暂时断线时沿用最后报价并显示过期状态。登记时间与价格时间独立，普通基金按净值所属日期显示，不能用抓取时间冒充行情日期。读取登记文件失败会显示错误并拒绝覆盖原文件。

Provider 的 `instrument_meta` 给出资产身份、数量单位、价格类型、净值日期时区和计价币转换标的；持仓与界面消费这些元数据。长桥报价币种和交易所符号格式由各自 Provider 负责，登记模块不解析来源代码。报价和来源/收到时间保存在同一个 `Quote` 内，生命周期一致。

价格变动按当前数量和来源参考价计算。加密资产参考 24 小时前，股票/ETF 参考前收盘，场外基金参考前一公布日净值；组合价格变动混合这些参考区间，不是统一的 24h 收益，也不包括买卖、资金流或汇率损益。只有一条净值或缺少前收盘价时，现价仍用于估值，变动显示未知；缺少参考价不等于缺少估值。成本按每单位填写，资产行只有在合并的每部分都有成本时才显示数量加权成本。

## 窗口结构

| 文件 | 内容 |
|---|---|
| `mod.rs` | 组合订阅、排序、小额折叠、标题栏、总览与登记管理界面切换 |
| `manual.rs` | 标的搜索与选择、数量/成本表单、登记列表、编辑和删除确认 |
| `summary.rs` | 分布、统计、说明行、排序、小额折叠和合约风险的纯计算 |
| `hero.rs` | 总额、价格变动和说明；金额变化时闪烁涨跌色 |
| `allocation.rs` | 资产分布条与图例 |
| `assets.rs` | 虚拟资产列表、来源位置、原生数量、换算后的价格/价值/成本 |
| `aside.rs` | 自动同步账户、按持有平台汇总的登记金额和合约仓位 |
| `tiles.rs` | 价格变动、非稳定币资产、稳定币和合约浮动盈亏 |

小额折叠始终采用美元价值不足 1 的口径。排序、是否显示小额、侧栏页签和管理界面状态只属于当前窗口。余额和行情刷新机制见 [market-data-providers.md](market-data-providers.md)，本地接口及字段以 `src/agent/SKILL.md` 为契约。

点击场外基金打开净值概览，显示公布净值、上海净值日期、相对前次净值的变动和历史净值曲线；曲线反映单位净值变化，不含分红再投资。点击 Au99.99 打开黄金价格概览，显示人民币每克价格、来源报价时间、真实日线及来源提供的统计。两个窗口都不显示盘口和逐笔成交；黄金基金仍按基金份额和净值展示，场内 ETF 沿用股票行情窗口。
